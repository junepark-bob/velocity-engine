1. **FEAT-macro-definition** (고객 이슈 #6): 글로벌 매크로 라이브러리 설정 키를 `velocimacros.library`에서 `velocimacro.library.path`로, 기본 파일을 `velocimacros.vm`에서 `velocimacros.vtl`로 정정.
   - 근거: `velocity-engine-core/src/main/java/org/apache/velocity/runtime/RuntimeConstants.java:328`(`VM_LIBRARY = "velocimacro.library.path"`), `:331`(`VM_LIBRARY_DEFAULT = "velocimacros.vtl"`).
2. **ADR-javacc-parser**: 문법 파일 경로를 `src/main/javacc/Parser.jj`에서 `velocity-engine-core/src/main/parser/Parser.jjt`로 정정(JJTree 문법, 빌드 때 `jjtree-javacc` 목표로 생성). 특수문자 변경은 `ParserConfiguration` 주입이 아니라 빌드 시점 속성이라고 정정. 결과 절의 `.jj`를 `.jjt`로.
   - 근거: `velocity-engine-core/src/main/parser/Parser.jjt`, `velocity-engine-core/pom.xml:40-43`(`parser.char.*`), `:108-133`(`javacc-maven-plugin` `jjtree-javacc`, `Parser.jjt`), `RuntimeConstants.java:441-452`.
3. **FEAT-custom-parser**: 특수문자 변경 시점을 런타임 주입에서 빌드 시점(Maven 속성 `parser.char.dollar`·`hash`·`at`·`asterisk`로 커스텀 파서 생성)으로, 런타임에는 `parser.class`로 지정(2.5부터 deprecated)이라고 정정. 요약·동작 방식·사용 예시(`runtime.custom_directives` 예시는 무관해 제거, `parser.class` 예시와 `@`/`%` 치환 예시로 교체). `code`에 `velocity-custom-parser-example/pom.xml` 추가.
   - 근거: `velocity-engine-core/pom.xml:40-43`, `velocity-custom-parser-example/pom.xml:37-45, 56-62`, `RuntimeConstants.java:441-452`·`:448`(deprecated), `velocity-custom-parser-example/src/test/java/org/apache/velocity/runtime/parser/CustomParserTestCase.java:32`(`parser.class` 사용).
4. **CTR-runtime-properties**: "새 키 추가 시 … 이 파일 `## 변경 이력` 업데이트" 문장을 현재 규칙으로 정정 — 새 키는 `RuntimeConstants`에 상수 선언, 기본값은 `velocity.properties`; `## 변경 이력`은 `kn generate`가 채우는 생성 구역이라 직접 고치지 않음; 계약 항목은 추가만. (이 낡은 문장 때문에 측정에서 계약 항목 편집 시도가 훅에 4건 거부됨)
