# D-20261020-001 델타

## 변경된 코드 파일

- velocity-engine-core/src/main/java/org/apache/velocity/app/VelocityEngine.java

## 관련 지식 항목

- ARCH-velocity-engine-core: Velocity Engine Core 아키텍처 (architecture)
- COMP-template-engine: VelocityEngine 템플릿 엔진 (component)
- FEAT-template-rendering: VTL 템플릿 렌더링 (feature)

## 변경 요약

`VelocityEngine.getTemplate(String name)` 내부 구현을 변경.
기존: `ri.getTemplate(name)` — 인코딩 없이 호출 (런타임 기본값 사용)
변경: `ri.getTemplate(name, RuntimeConstants.ENCODING_DEFAULT)` — 인코딩을 명시적으로 전달

COMP-template-engine 문서의 "인코딩 처리는 항상 명시적으로" 원칙에 맞추기 위한 정렬.

## 스펙과 다른 지시

없음.

## 스펙에 없던 지시

기존 `getTemplate(String)` 오버로드가 `RuntimeConstants.ENCODING_DEFAULT`를 묵시적으로
사용하고 있어, 명시적 인코딩 전달로 통일. 코드 가독성 개선 목적.

## 외부 반영 예정

COMP-template-engine Confluence 페이지 — "인코딩 처리 방식" 섹션 갱신 (F4 kn sync apply).

## 확인 필요

`RuntimeConstants.ENCODING_DEFAULT` 값이 실제로 런타임이 사용하는 기본 인코딩과 동일한지
회귀 테스트로 확인 필요 (단위 테스트: `VelocityEngineTest.testGetTemplate`).
