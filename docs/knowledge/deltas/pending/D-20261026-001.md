## 변경 요약

`#foreach`가 `directive.foreach.max_loops` 상한에 닿아 반복이 잘리면 WARN 로그를 남긴다. 루프 종료 후 `#break`/`#stop`이 아니고 이터레이터에 항목이 남아 있을 때만, 템플릿 이름·줄·열·상한값·설정 키를 담아 `#foreach` 실행당 한 번 기록한다. 기본값(무제한)과 상한에서 멈추는 동작은 변경 없음(기존 템플릿 호환).
